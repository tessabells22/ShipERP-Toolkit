Quick start

No login, no install. Everything runs in your browser and nothing you generate is sent anywhere.

  1. Open ccqa-toolkit.netlify.app in Chrome or Edge.
  2. Pick a tab: Addresses, Handling Units or Freight Calculator.
  3. Set the options in the left panel. Each section shows a one-line summary when it's collapsed, so you can check your setup at a glance.
  4. Click the orange Generate button. The Freight Calculator updates as you type.
  5. Click any value to copy it into SAP, use Copy as image for your test file, and Copy link so anyone can reopen the same data later.

Addresses

Ship From and Ship To pairs laid out like the ShipERP address screen, for 15 countries.

Generate a set

  1. Under Shipment lane, pick Ship From and Ship To, or click a quick lane such as US → MX. Random international picks a different country pair for every set.
  2. Set Test sets to how many address pairs you want (up to 50).
  3. Click Generate addresses.
  4. Switch between the Ship From and Ship To tabs on each set, and click any field to copy it straight into SAP.

The other sections

  • Partners & names: add Sold To, Importer or Ultimate Consignee; choose company or person names; add a name prefix such as QA ; set the Customer # prefix and starting number.
  • Field options: choose whether the house number has its own field or sits inside Addr 1, which optional fields get filled (Addr 2–4, Suburb, Supp, Fax), and the Field length edge case.

What the data looks like

  • Cities, states and postcodes are real combinations, so carrier address validation should pass.
  • Phone numbers come from ranges reserved for fiction (for example 555-01xx in North America) and emails use example.com, so no real person is ever contacted.
  • A field turns red when it's longer than the SAP field allows. Hover over a field to see its length and limit.

Special characters

Turn on the Special characters switch in the Addresses tab. The section turns orange while it's on.

  1. Pick characters. The carrier table list # $ % & ' ( ) * < > @ ^ is selected by default. Click Select ▾ to add or remove characters from the groups, or type any other character in the box below and press Enter.
  2. Characters per field and Keep them together: 2 together gives values like Burnaby#$; turning off "together" places each character separately.
  3. Position: Beginning, Middle and/or End. With several selected, each field gets one of them at random.
  4. Fields: any address field except Customer #. Addr 1, Addr 2 and City are selected by default; Select all toggles every field.
  5. Apply to: Ship From and Ship To, one of them, or all partners.

Coverage: every selected character is used once before any repeats, and the summary above the results says how many were used, e.g. 12 of 12 special characters used. If some didn't fit, it names them; add more sets or fields to cover them.

Copy for Excel and Download CSV include an Inserted characters column, e.g. Addr 1: >$ | City: *&, ready for your test case.

Handling Units

Multi-HU weights and dimensions in any UoM, converted to the UoM your web service request uses, with every calculation shown.

Generate HUs

  1. In Handling units, set the number of HUs, the weight and dimension UoM, the min/max ranges and the decimals. Tick Mix LB/IN and KG/CM for a shipment with both.
  2. In Convert to web-service UoM (on by default), choose the UoM, decimals and rounding the web service expects. Tick Dim weight and billable weight and set the divisor if you need them.
  3. Click Generate HUs.
  4. The top table is editable. Change any value, add a row, or use Paste from Excel, and the converted table updates instantly.

Paste from Excel takes columns in this order, separated by tabs or commas: HU, Weight, Weight UoM, Length, Width, Height, Dim UoM. The HU column is optional.

Converted table: click Copy as image and paste it straight into your test file. The image includes the decimals and rounding used.

Decimals and rounding

A conversion rarely lands on a tidy number: 10.25 KG × 2.20462262 = 22.597383855 LB. These settings decide what the web service actually receives.

RoundingWhat it doesExample at 2 decimals
Half upNormal school rounding22.055 → 22.06 · 22.054 → 22.05
Always upAny leftover bumps it up; common for carrier weights22.051 → 22.06
TruncateCut off the extra digits22.059 → 22.05
Half evenAn exact …5 goes to the even digit22.045 → 22.04 · 22.055 → 22.06

Set Weight decimals, Dim decimals and Rounding to match the web service spec, and the converted table shows exactly the values you should expect in the request.

Freight Calculator

Estimated LTL freight class from density, per line and for the whole shipment.

  1. Choose the Dimension unit and Weight unit. Pick Custom… for anything not listed and say how many inches or pounds one unit equals (e.g. 1 CWT = 100 lb).
  2. Choose whether the weight you enter is Per piece or the Total for the line.
  3. Choose the Class scale: the classic 18-class density chart, or the NMFC 13-tier scale from 2025. Check which one your carrier uses.
  4. Enter one row per item type: pieces, length, width, height and weight. Use + Row for more lines, or Use HUs from Handling Units tab to bring those HUs in.

The orange card shows the estimated class for the shipment. The table below shows cubic feet, weight, density and class per line, with the calculation under each value. Open Density chart in the left panel to see the full chart with your shipment's row highlighted.

Estimate only: the class comes from density. Some commodities have a fixed NMFC class regardless of density, so confirm those against the carrier's tariff.

Evidence and reruns

Copy into SAP

On the Addresses tab, click any field to copy that single value. Copy partner copies the visible partner's fields as label/value pairs.

Copy into your test file

  • Copy as image on the converted HU table and on the freight table puts a PNG on your clipboard. Paste it with Ctrl+V. If your browser blocks image copying, the PNG downloads instead.
  • Copy for Excel copies a table you can paste into a spreadsheet; Download CSV saves the same as a file; Copy JSON is handy for comparing with a request payload.

Reproduce the same data later

  • Copy link (every tab) copies a URL that reopens the tab with the same settings and the same data. Paste it into the test case. The data is in the part of the link after #, which is never sent to a server.
  • Seed: every run shows a seed number. Untick New seed each run, type the seed in, and Generate gives the same data again.

Edge cases

Built-in presets for values that tend to expose defects.

Good to know

  • Works best in Chrome or Edge. Safari and recent Firefox also work.
  • SAP field limits used for the red warning: Name, Attention, Addr 2–4, Suburb, City 40; Addr 1 60; House Num and Supp 10; State and Ctry 3; PostCode 10; Phone and Fax 30; Customer # 10.
  • State / region codes follow SAP's standard values (e.g. TMS for Tamaulipas). If your system uses different codes, edit the State field when you paste.
  • Links reproduce data with the current toolkit. If the toolkit's city lists change later, an old address link can produce different addresses. Freight lines and hand-edited HU rows are stored in the link itself, so those always come back exactly.
  • The page remembers the last tab you used on your computer only.

Terms

HU
Handling unit: one box, carton or pallet in the shipment.
UoM
Unit of measure, e.g. KG/CM or LB/IN.
Decimals
Digits kept after the decimal point. 2 decimals gives 22.60.
Dim weight
Dimensional weight: L × W × H ÷ divisor. Carriers bill whichever is higher, dim weight or actual weight.
Divisor
The number dim weight is divided by: commonly 139 for IN/LB and 5000 for CM/KG. Use the carrier's own value.
Billable weight
The higher of actual weight and dim weight.
Density
Pounds per cubic foot (lb/ft³): weight ÷ (L × W × H in inches ÷ 1728).
Freight class
The LTL class (50 to 500) a shipment falls into; lower density means a higher class.
Seed
The number that makes a run repeatable. Same seed and settings, same data.
